Unreal Engine



Cinematic


A short cinematic created entirely in Unreal Engine. The environment was built from scratch, with models sourced from Sketchfab and animations from Mixamo. Textures were produced using JSplacement and mixed with native Unreal Engine assets and assets from Textures.com.



Transformation Logic


Designed a prototype transformation logic using existing game meshes of a game. Each form features its own control scheme, showcasing dynamic input switching and seamless transition effects within Unreal Engine.

Other Projects



TAMM-E AI Assistant


An ongoing project: TAMM-E is an on-campus AI assistant designed to welcome students and visitors at FEU Tech. It runs fully offline on both Windows and Linux, and can be easily updated with the latest campus events and announcements. Developed with Python 3.11, Ollama, and a combination of open-source STT, TTS, and RAG models. The Unity Wayfinder component was created by a colleague.



Eagle Website


A functional social-media-style web platform built with PHP and XAMPP, featuring user accounts, posts, and a SQL-driven backend. The project highlights database design, authentication logic, and front-to-backend integration.
